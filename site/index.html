How it works

Thousands of events in, a short ranked list out.

KubeHealth reads your cluster's warning events and turns them into one row per broken workload, newest first.

kubectl get events -Awhat Kubernetes gives you
  • Warning BackOff pod/orders-worker-657b5…-wksdm ×64
  • Warning BackOff pod/orders-worker-657b5…-h8zg7 ×58
  • Warning FailedScheduling pod/orders-db-0 ×20
  • Warning ProvisioningFailed pvc/data-orders-db-0 ×82
  • Warning BackOff pod/search-indexer-7f7b7…-26p9t ×30
  • Warning Unhealthy pod/storefront-7654d…-q8w2d ×16934
  • Warning Failed pod/checkout-api-5c4bc…-xfk9f ×117
  • Normal Pulled pod/orders-worker-657b5…-wksdm ×9
  • … and hundreds more, across every namespace
KubeHealth overviewone row per broken workload
  1. new
    search-indexerDeployment · searchBackOff ×30 · ran out of memory · 1 pod
  2. ongoing
    orders-workerDeployment · ordersBackOff ×122 · 3 pods · failing for 5 h
  3. chronic
    storefrontDeployment · frontendreadiness probe failing ×16,934 · for 2 days
Grouped by ownerPods, ReplicaSets and Jobs roll up to their Deployment, CronJob or StatefulSet: fifty failing pods are one row.
Ranked by ageNew (under 2 h) first, then ongoing, then chronic, so an old failure never hides a fresh one.
Merged across namespacesThe same failure in several namespaces at once becomes a single row.
Easy on the clusterRead-only: one list call every 2 seconds, everything else from its cache.
What you get

Triage first, details one click away.

The namespace list never leaves the screen. Pick a namespace for its live status, pick an object for its ownership chain and full timeline, ask for logs or a root cause without changing pages.

Run it

Download a build from the releases page, then:

Regular build macOS, Linux, Windows 
tar -xzf kubehealth_*_darwin_arm64.tar.gz
cd kubehealth_*_darwin_arm64
xattr -d com.apple.quarantine kubehealth  # macOS
./kubehealth                    # localhost:8080
Embed build model bundled, AI offline 
tar -xzf kubehealth-embed_*_darwin_arm64.tar.gz
cd kubehealth-embed_*_darwin_arm64
xattr -d com.apple.quarantine kubehealth-embed
./kubehealth-embed              # + local model
