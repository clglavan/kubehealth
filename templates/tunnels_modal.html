Tunnels

Commands that open the way to private clusters. KubeHealth starts a cluster's tunnel when you pick the cluster, restarts it if it drops while you watch that cluster, and stops what it started when it exits.

KubeHealth reaches the cluster through it as
For -D (SOCKS, as in the gcloud example) or an HTTP proxy. KubeHealth waits for this port to open.
For -L 16443:<api server>:443 and port-forwarding sessions: where the API server answers locally. Its certificate is still checked against its real name.
The command routes traffic itself (sshuttle, a VPN client): KubeHealth starts it and gives it a few seconds.
